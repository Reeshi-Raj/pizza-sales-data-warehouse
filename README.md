# 🍕 Pizza Sales Data Warehouse using MySQL

A comprehensive SQL project that analyzes pizza sales data using advanced MySQL concepts. The project focuses on solving real-world business problems through database design, analytical SQL queries, reusable database objects, and automation techniques.

---

# 📌 Project Overview

This project demonstrates how relational databases can be used for business analytics rather than only storing transactional data.

Using a real-world pizza sales dataset, the project answers important business questions related to revenue, customer orders, product performance, and sales trends while showcasing advanced SQL development skills.

---

# 🎯 Objectives

* Design a normalized relational database.
* Analyze sales data using SQL.
* Generate meaningful business insights.
* Implement reusable SQL components.
* Automate database operations.
* Optimize query performance.

---

# 🗂 Dataset

The project contains four relational tables.

| Table         | Description                                     |
| ------------- | ----------------------------------------------- |
| orders        | Stores order date and order time                |
| order_details | Stores pizzas included in each order            |
| pizzas        | Stores pizza size and price                     |
| pizza_types   | Stores pizza names, categories, and ingredients |

# 🚀 How to Run

1. Clone the repository.
2. Open MySQL Workbench.
3. Create a new database.
4. Execute the SQL scripts in the following order:

```text
create_tables.sql
constraints.sql
import_data.sql
indexes.sql
basic_queries.sql
intermediate_queries.sql
advanced_queries.sql
procedures.sql
functions.sql
triggers.sql
views.sql
```
